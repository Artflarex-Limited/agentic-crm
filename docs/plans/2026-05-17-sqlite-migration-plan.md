## Architecture After Migration

| Layer | Before | After |
|-------|--------|-------|
| ORM | SQLAlchemy (Python models in `models.py`) | **Prisma Client Python** (`schema.prisma`) |
| Migrations | Alembic (`alembic/versions/`) | **Prisma Migrate** (`prisma migrate`) |
| DB client | `get_async_session_local()`, `async with session` | `prisma.model.find_many()`, `prisma.model.create()` |
| Models | Python classes in `app/models/models.py` | `schema.prisma` (auto-generated Prisma Client) |
| Database | PostgreSQL | **SQLite** via Prisma |
| Agent tasks | Celery `@celery_app.task` | FastAPI `BackgroundTasks` |
| Task broker | Celery + Redis | **None** (fire-and-forget BackgroundTasks) |

## Prisma ↔ SQLAlchemy Query Mapping Reference

| SQLAlchemy | Prisma Client Python |
|-----------|----------------------|
| `db.execute(select(Model).where(...))` | `prisma.model.find_many(where={...})` |
| `db.execute(select(Model).where(Model.id == id))` | `prisma.model.find_unique(where={'id': id})` |
| `db.execute(select(Model)).scalar_one_or_none()` | `prisma.model.find_first(...)` |
| `db.add(obj); await db.commit()` | `await prisma.model.create(data={...})` |
| `db.query.filter(...).update({...})` | `await prisma.model.update_many(...)` |
| `db.flush()` | implicit in Prisma create/update |
| `await db.refresh(obj)` | await the same call or re-fetch |
| `db.query.filter(...).all()` | `prisma.model.find_many(...)` |
| `db.query.count()` | `prisma.model.count(...)` |
| `selectinload` / `joinedload` | `include` param: `include={'contacts': True}` |
| JSON column | SQLite stores as text; use `json.dumps()` / `json.loads()` |
